# MKM-SHOP - E-Commerce Web Application

## Project Description
MKM-SHOP is a modern, responsive e-commerce web application built using ReactJS and Bootstrap. It allows users to browse products, view product details, add items to a shopping cart, and navigate seamlessly across multiple pages.

## Pages & Features
- *Home*: Welcome banner, product categories, and promotional sections.
- *Products*: Complete catalog of items with interactive UI elements.
- *About*: Story, vision, and core mission of the platform.
- *Contact*: User inquiry form and localized business communication channels.
- *Cart*: Dynamic shopping cart interface for reviewing selected products.

## Technologies Used
- *Frontend Framework*: ReactJS
- *Routing*: React Router DOM (HashRouter)
- *Styling & UI Components*: Bootstrap 5 & Bootstrap Icons
- *Version Control*: Git & GitHub
- *Deployment*: GitHub Pages
